# shortitems: Short Items

Draws held items smaller in first person, in either hand, as 1.8 PvP packs drew swords. Reach and
hits are unchanged. Was Short Swords (swords only); its id is still `shortswords`, so profiles keep
it. ([ADR 0062](../../docs/adr/0062-incari-settings-and-the-2026-10-12-batch.md))

| Setting | Kind | Default |
| --- | --- | --- |
| Size | 40-100% | 70% |
| Also while in use | on/off | on |

```sh
./gradlew :features:shortitems:check
```
