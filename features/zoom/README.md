# zoom: Zoom

Hold (or toggle) the key to zoom in, as OptiFine's zoom: the world's field of view narrows, the hand
and HUD stay as they are, and the view turns smoothly. Letting go zooms back out.

| Setting | Kind | Default |
| --- | --- | --- |
| Zoom key | keybind | C |
| Key | Hold, Toggle | Hold |
| Zoom | 2x to 10x | 4x |
| Turning | Smooth, Slower, As usual | Smooth |
| Ease in and out | on/off | off |

C is also the game's Save Hotbar Activator (creative only); OptiFine shares it the same way.

```sh
./gradlew :features:zoom:check
```
