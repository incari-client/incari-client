# saturation: Saturation

Shows saturation, the hidden food value that keeps hunger from dropping, on the hunger bar: each
shank's worth outlines that shank in a bright color, from the right, as AppleSkin does. When the
outline is gone, hunger starts going down.

| Setting | Kind | Default |
| --- | --- | --- |
| Color | colour | Gold |

```sh
./gradlew :features:saturation:check
```
